# 五分钟内测

只使用无敏感测试文字，不发送消息。以下替换与撤回都可用本地草稿，不需要 AI 请求。

```text
前文〔保留A🙂〕
帮我整理复习计划🙂。保留现有资料。不要发送消息。
后文〔保留B〕
```

1. 在文本编辑中只选中中间一行，不包含换行；进入“⋯ → 使用本地草稿”。
2. 检查后点“替换选中文字”。只有中间选区变化，首尾两行与 emoji 保持不变，建议正文之外无多余留白。
3. 点击助手里的“撤回上次替换”，先不用 ⌘Z。全文应逐字恢复，原句仍被选中，留白正常。
4. 取消再选同一片段，连续做三轮替换与按钮撤回。每轮分别记录，浮条应再次出现，没有错位或重复写入。
5. 在常用软件、浏览器普通输入框和富文本中重复；富文本选区之外的粗体/斜体等应保留。

可加测：两处相同文字只替换第二处；预览后改文/改选时旧建议不写入；快速交替选区；按应用禁用与恢复。

AI 测试自愿，使用自己的兼容账号环境：用一段无敏感文字点击一次“AI 完善”，观察加载、等待秒数、结果返回和是否出现文件授权。不要为完成测试授予文稿或完全磁盘访问。
