## 三层接入

1. **发现层**：[discovery-index.json](../skills/agent-learning-loop/references/discovery-index.json) 保存链接、原生分类、维护与许可元数据、目录／文件 SHA、阅读范围。它不进入每次 AI 请求。
2. **方法层**：[领域方法](method-catalog.md)是独立写成的简短适配，目前为 14 个方向、17 张方法卡、36 条方法来源记录；这些数字与上面的发现来源有重叠，不能相加。
3. **个人选择层**：[偏好工具](preferences.md)单独保存用户确认的选择。源库推荐不自动成为个人喜好；选中一句话不会触发整库扫描。

0.8 安装包内置精简领域配方、17 种方法及原生偏好菜单，领域匹配使用本地关键词。资料研究由宿主协作工作流完成，应用不会自行下载、安装或执行这里的 Skill。安装包只带构建时快照；仓库和宿主方法数据更新不代表旧 ZIP 里的快照已经更新。

## 已读之后采用了什么

本轮具体审读包括：Superpowers 的验证正文及调试／规划章节；Context Engineering 的压缩、记忆、评估与基础章节；K-Dense 的文献、图表与审稿章节；Spec-kit 两个 workflow 定义；Vercel、Supabase、Remotion 的入口正文；Expo UI 章节；Trail of Bits 的上下文构建正文；三篇 Willison 指南及 Mollick、Anthropic 文章的指定范围。逐条范围与不可变 blob SHA 见数据索引，引用文件和脚本没有因此视为已读或已运行。

已有方法补充了跨组件排查证据、实际用户路径验收、可追溯检索范围和按需加载资料。另提供三个可选方法：**上下文接续、结果验收、证据图表**。它们不会静默取代原有默认方法或个人选择。

参考资料中没有采用的要求包括：无条件增加 Agent、每次都设审批门、固定样例数量、固定模板长度、强制公开推理过程，以及未经核实的质量／压缩数字。Spec-kit 定义里的审核门和 Trail of Bits 的子 Agent 路由是上游设计，不能变成本项目新的强制规则。Mollick 2023 年文章的模型、价格和情绪措辞建议也未作为当前通则。

## 状态要能核对

- `indexed`：看过目录条目，具体正文未审读。
- `section-reviewed`：读了指定章节或字符范围，剩余内容和依赖不视为已读。
- `body-reviewed`：读完当前具体文件正文，引用文件和脚本仍需单独检查。
- `execution.status = not-run`：本库全部如此。静态审读不证明运行结果，更不证明 Snapper 的 AI 输出质量提升。

Git tree SHA 标识目录内容，不是 commit SHA；阅读记录另存具体文件 blob SHA。目录变化后旧审读不能沿用；网页没有内容指纹时必须重新核对。许可证字段来自仓库元数据或入口声明，未逐项审计；此处只发布链接、目录事实和独立概括，没有打包第三方 Skill 正文或代码。

发现的维护问题也会保留：[K-Dense 旧仓库名](https://github.com/K-Dense-AI/claude-scientific-skills)已指向新仓库；[AutoGen README](https://github.com/microsoft/autogen)声明不再维护，而 API 的 archived 字段仍为 false；[CrewAI examples](https://github.com/crewAIInc/crewAI-examples)与 Anthropic courses 已归档。CrewAI examples 指向的 cookbook 本轮返回 404，记录为未解决线索，未计入已核对来源。

## 检索与持续更新

```sh
python3 scripts/source_index.py inventory
python3 scripts/source_index.py search 数据库 --limit 5
python3 scripts/source_index.py search 视频 --source remotion-dev/skills
python3 scripts/source_index.py plan --limit 24 --output /tmp/source-review-plan.json
python3 scripts/source_index.py --index new-index.json diff old-index.json
python3 scripts/source_index.py merge new-index.json --output /tmp/merged-index.json
python3 scripts/test_source_index.py
```

这是本地词项和中英别名检索，排序分数不等于质量排名或语义理解。检索结果显示范围、维护与许可状态，推荐标记始终为 false。

每周流程同时保留完整作者清单扫描、新人物发现和来源库变化检查。具体正文按来源轮换，再按原生分类轮换；默认每轮 24 项，可按任务调整，没有“所有 1,182 项每周读完”的承诺。归档来源仍需检查迁移，但不占普通新方法审读队列。生成清单只会留下 pending，实际浏览后才能记录已读、检查无新增、不可访问或延后。

更新时用连接器读取当前元数据与目录，保存新的候选快照；先比较增删和 SHA 变化，再合并同一版本的旧审读。新条目保持 indexed，逐项记录真正读过的范围与适用条件。检查数据约束、模板构建与偏好保留后，才原子发布精简方法快照。发布失败继续沿用现有数据。完整发现库留在研究层，不增大每次模型上下文。

公开源库不包含个人偏好、账号、私有项目资料或开发者的定时任务。额外模型比较仍由使用者按自己的授权范围发起。
