# 0.10.0 beta · 邀请码共享 AI

构建 14，2026-11-19。已安装本机正式路径并恢复原有辅助功能权限；邀请码连接已在真实桌面界面完成。本文件记录打包时的实际验收；当前下载状态见 [GitHub Release](https://github.com/shian493719730-art/snapper-assist/releases/tag/v0.10.0-beta.1)。

朋友使用默认共享模式，无需安装 Codex、配置 API 或获得维护者密钥。在授权页或菜单栏 S 打开“共享 AI 与邀请码…”，粘贴单独提供的邀请码即可连接。原有领域偏好、本地草稿、替换和撤回代码保留；本机 Codex 留作明确选择的另一种接入，不作静默收费回退。

按维护者确认，**真实扣费关闭，初始全局与个人额度/次数均为零**。邀请码连接、状态查询与生成拦截已在实际托管服务验证；连接成功不代表付费生成已开放。

模型凭据已接到服务端并加密保存，不进入安装包或公开源码。云端与本机均以真实凭据成功读取 TideVerse 模型目录，所选模型可用；没有发送任何收费生成。云端请求兼容问题已修正，并增加拒绝转发重定向的回归检查。

服务提供：单设备邀请码、有效期、撤销；总额度、个人额度、每日与总次数限制；原子预留、计量结算、异常时保留额度；请求 ID 去重；两次模型调用间检查停用状态。维护者可独立管理邀请码与限额，客户端不能打开真实扣费。维护者私有凭证与邀请码不公开分发。

已通过 **77 项原生回归、52 项随包方法、20 项共享服务测试**，以及源码/数据/文档检查。共享服务测试使用真实 SQLite 和模拟模型，覆盖并发、重放、到期、撤销、零额度、停用、使用量、异常保留、服务端凭据加密与重定向拦截。线上激活/状态请求返回成功；关闭扣费时生成接口返回 403，不产生模型调用。

尚未进行本版真实收费生成、模型输出质量对照、新电脑首次安装或完整跨软件替换/撤回验收。初次 Mac 权限仍可能需要重新确认：当前为 ad-hoc 签名、尚未公证。个人偏好和数据保留，有升级前应用及数据备份。
