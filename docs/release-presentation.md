# Launch presentation notes

Reviewed 2026-11-10. The launch page borrows communication structure, not product claims, from established projects:

- [Rectangle](https://github.com/rxhanson/Rectangle): concise purpose, requirements and a direct installation path.
- [Stats](https://github.com/exelban/stats): prominent download, compact feature list and useful troubleshooting.
- [Raycast Extensions](https://github.com/raycast/extensions): separate getting-started, contribution and feedback routes.

Applied here: app-first English/Chinese READMEs, a direct tagged beta download, a clearly labeled workflow diagram, upfront hardware/AI requirements, source-backed methods, data boundaries, a test checklist and structured issues. The graphic is a diagram, not an actual app screenshot or runtime proof.

No borrowed stars, fabricated testimonials, usage counts, endorsements or promise of widespread attention are used. Fresh-machine install and compatibility gaps stay visible. A small beta release is an opportunity to gather evidence, not evidence of product-market fit.
