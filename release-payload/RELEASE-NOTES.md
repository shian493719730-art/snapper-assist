# Snapper Assist 0.10.5 beta

## 本版变化

- **支持官方 Claude API**。在「AI 连接」里使用自己的 Anthropic 密钥，配置存入 macOS 钥匙串。Claude 先按选文挑选相关方法，再用实际所选的 Skill 正文改写。
- **复制文字也能完善**。在 Codex 等编辑器中复制文字后，点菜单栏 **S → 处理已复制文字**，预览后再点 **Claude 完善**。结果可以复制回编辑器。这个入口无需辅助功能权限。
- **修复授权窗口和阶段切换**。重新打开助手可见独立授权窗口。选完 Skill 后的改写进度更新回到主线程，避免原有浮窗闪退。
- **改进读选区失败时的反馈**。已授权的应用若暂时读不到选中文字，会说明情况并给出复制入口。读取系统选区范围时会校验 UTF-16 边界。

## 下载与使用

Apple 芯片 Mac，macOS 26+。安装包采用临时签名（ad-hoc），更新后自动选文可能需要为当前副本重新确认辅助功能权限。[中文安装说明](../install.zh-CN.md) · [English setup](../install.md)。

官方 Claude 请求由你点击发起，费用来自自己的 Anthropic 账户。共享 AI 邀请方式仍保留，默认托管生成扣费关闭。

## 验证范围

ZIP 的程序与本机安装版逐字节一致，严格签名校验通过。通过 80 项原生回归及 52 项随包方法检查。Claude 阶段切换使用模拟数据测试，发布验收未发付费请求。Codex 底部输入框的自动浮条仍待实机验证。
